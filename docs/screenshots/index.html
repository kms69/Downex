Everything you expect from a real download manager

Built for people who download a lot and hate waiting.

⚡

Multi-connection speed

Splits each file into segments and downloads them in parallel to use your full bandwidth.

⏯

Pause and resume

Stop any time, even after a dropped connection, and carry on from where you left off.

🎬

Video downloads

Grab videos from YouTube, Instagram, TikTok and more, choosing the quality you want.

🧩

Browser extensions

Brave, Chrome, Edge and Firefox. A download bar appears right on the video you are watching.

🗓

Queues and scheduler

Line downloads up and start them when you want, for example overnight.

🎚

Speed limiter

Cap the bandwidth so downloads never get in the way of your calls and browsing.

Install in a minute

Downix is not yet notarized by Apple, so macOS shows a warning the first time. It is safe to open.

Download

Get Downix.dmg from the latest release and drag Downix into Applications.

Or use Homebrew

Run brew tap kms69/downix, brew trust kms69/downix, then brew install --cask downix.

Open it

If macOS blocks it, go to System Settings → Privacy & Security and click Open Anyway. Or run:

xattr -dr com.apple.quarantine /Applications/Downix.app

Add the extension

Download the extensions zip from the release, then load the folder for your browser from its extensions page (Developer mode → Load unpacked).

Why the warning? Apple charges $99 a year to notarize apps, and this is an independent project. If Downix gets enough stars we will do it, so the warning goes away.
